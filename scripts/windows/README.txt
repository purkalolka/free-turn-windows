FreeTurn Desktop Portable
=========================

Инструкция:
1. Для работы встроенного системного VPN (режим Wintun / WireGuard) приложению требуются права администратора, чтобы создать сетевой адаптер FreeTurn и прописать маршруты в системе.
   - Запускайте через `Run_Admin.bat` или правой кнопкой мыши по `FreeTurn.exe` -> "Запуск от имени администратора".
2. Файл `wintun.dll` должен лежать рядом с `FreeTurn.exe`.
3. В приложении:
   - Вставьте ссылку `freeturn://` от вашего сервера или настройте профиль вручную.
   - Выберите режим подключения "VPN" для полного туннелирования трафика через виртуальный адаптер Wintun.
